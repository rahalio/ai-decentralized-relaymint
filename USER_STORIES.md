# Relaymint — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### NGO programme director

- As an NGO director, I want to fund a Dhaka-density campaign with clear KPIs, so that connectivity gains are measurable against our grant obligations.
- As an NGO director, I want to pause payouts during public unrest, so that we do not incentivize unsafe gathering behaviour.

### Brand marketing lead

- As a brand lead, I want to sponsor mesh density around disaster-response apps, so that our CSR spend maps to reachable users in connectivity blackouts.
- As a brand lead, I want to compare cost per connected user against our incumbent media spend, so that I can justify renewal.

### App distributor / publisher

- As an app distributor, I want to co-fund density where my app launches offline-first, so that downloads convert because mesh coverage exists.
- As a publisher, I want token or fiat rewards routed to local gateway operators, so that content delivery improves as density grows.

### Field verification analyst

- As a verification analyst, I want to attest coverage samples from mesh telemetry feeds, so that rewards release only on evidence.
- As a verification analyst, I want to flag suspicious inflation of node counts, so that sponsors are not billed for ghost density.

### Finance controller

- As a finance controller, I want escrow and milestone statements, so that multi-year $10–20M programme budgets reconcile without manual spreadsheets.

### Platform administrator

- As a platform administrator, I want jurisdiction rules blocking non-compliant token campaigns, so that securities exclusions from the RightMesh deck are enforced by default.
- As a platform administrator, I want negative-path holds when attestation feeds fail, so that campaigns do not auto-pay on stale telemetry.
